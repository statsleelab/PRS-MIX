simulate_null_gwas.R — implemented math

Companion to inst/scripts/simulate_null_gwas.R. The script draws a null GWAS summary-statistics file (no real genotype-phenotype association anywhere) that still carries the same LD-induced correlation between nearby SNPs a real null dataset would have, using an already-built LD reference panel (panel_dir) as the source of both that correlation structure and the allele frequencies needed to put the result on PRS-CS's expected scale.

1. Reference panel inputs

  • One LD block at a time, $m$ SNPs in the block, indexed by $j$.
  • Block correlation matrix $R \in \mathbb{R}^{m\times m}$, read from ldblk in the panel's HDF5 file.
  • Allele frequency $\mathrm{maf}_j$ per SNP, read from snpinfo_1kg_hm3 and looked up via maf_by_snp.
  • Simulated GWAS sample size $n$, the script's n_gwas argument.

R <- as.matrix(blk[["ldblk"]]$read()), maf <- maf_by_snp[snplist] in simulate_null_gwas.R.

2. Null target distribution

The quantity being simulated is a vector of null z-scores for the block, with exactly $R$ as its covariance:

$$ z \sim \mathcal{N}(0,\, R), \qquad z \in \mathbb{R}^{m}. $$
Drawing each $z_j$ independently would set $\mathrm{Cov}(z)=I$ instead of $R$. Real null GWAS noise isn't independent across nearby SNPs — two SNPs in LD still produce correlated effect-size estimates under the null, purely because their genotypes are correlated. Simulating $z\sim\mathcal{N}(0,R)$ reproduces that; i.i.d. noise would not.

3. Cholesky factorization

$R$ is factored as $R = U^{\top}U$ with $U$ upper-triangular. Drawing $w$ i.i.d. standard normal and setting $z = U^{\top}w$ gives the target covariance exactly:

$$ \mathrm{Cov}(z) = \mathrm{Cov}(U^{\top}w) = U^{\top}\,\mathrm{Cov}(w)\,U = U^{\top} I\, U = U^{\top}U = R. $$ 
U <- chol(R)
w <- stats::rnorm(m_snps)
z <- as.vector(crossprod(U, w))

4. Converting $z$ to a sumstats row

$z$ lives on a standardized scale — it has nothing to do with allele counts or units yet. A real GWAS sumstats file reports a per-allele BETA (how much the trait changes per copy of the effect allele) and a two-sided P. This section derives the three lines that make that conversion, one piece at a time.

4.1 Where the standard error comes from

For a single-SNP linear regression of a standardized phenotype ($\mathrm{Var}(Y)=1$) on genotype dosage $X_j\in\{0,1,2\}$, ordinary least squares gives an estimated effect $\hat\beta_j$ whose standard error is, for large $n$,

$$ \mathrm{se}(\hat\beta_j) \;\approx\; \frac{\sigma_Y}{\sqrt{n\cdot \mathrm{Var}(X_j)}} \;=\; \frac{1}{\sqrt{n\cdot \mathrm{Var}(X_j)}}. $$

This is the ordinary "standard error shrinks with more samples, and with more variation in the predictor" fact from regression — more copies of an allele actually varying across people means each person's genotype carries more information about $\hat\beta_j$.

$\mathrm{Var}(X_j)$ itself is a population-genetics fact, not a free parameter: under random mating, each of the 2 allele copies at a SNP is independently the effect allele with probability $\mathrm{maf}_j$, so $X_j$ is Binomial$(2,\mathrm{maf}_j)$, and

$$ \mathrm{Var}(X_j) = 2\,\mathrm{maf}_j(1-\mathrm{maf}_j). $$

Substituting gives the line in the script:

$$ \mathrm{se}_j = \frac{1}{\sqrt{2\,n\,\mathrm{maf}_j(1-\mathrm{maf}_j)}}. $$ 
se <- 1 / sqrt(2 * n_gwas * maf * (1 - maf))
A common SNP ($\mathrm{maf}_j$ near 0.5) has larger $\mathrm{Var}(X_j)$ and so a smaller $\mathrm{se}_j$ than a rare one ($\mathrm{maf}_j$ near 0) at the same sample size — rarer variants get noisier effect-size estimates, exactly as in a real GWAS.

4.2 Where $\beta_j = z_j \cdot \mathrm{se}_j$ comes from

This isn't a new assumption — it's just the definition of a z-statistic, rearranged. A Wald z-statistic is, by definition, an estimate divided by its own standard error:

$$ z_j \;:=\; \frac{\hat\beta_j}{\mathrm{se}_j} \qquad\Longrightarrow\qquad \hat\beta_j = z_j \cdot \mathrm{se}_j. $$

We simulated $z_j$ directly in Section 3 (that's the quantity with the correlation structure we care about), and Section 4.1 just supplied $\mathrm{se}_j$. Multiplying them recovers a $\hat\beta_j$ on the ordinary per-allele scale — same relationship any real GWAS's $\hat\beta$, $\mathrm{se}$, and $z$ satisfy.

beta <- z * se

4.3 Where the p-value comes from

Under the null, the Wald statistic $z_j$ is asymptotically standard normal. A two-sided p-value is just "how much of the normal distribution is at least this extreme, in either direction":

$$ p_j = \Pr(|Z| \ge |z_j|) = 2\bigl(1-\Phi(|z_j|)\bigr), $$

where $\Phi$ is the standard normal CDF.

p <- 2 * stats::pnorm(abs(z), lower.tail = FALSE)

4.4 Why deriving both from the same $z$ matters

Downstream, PRS-CS doesn't read BETA's magnitude directly — it reconstructs its own working z-score from BETA's sign and P alone (the same reconstruction used for the validation figure in this repo):

$$ z_j^{\mathrm{recovered}} = \mathrm{sign}(\beta_j)\cdot \Phi^{-1}\!\left(1-\tfrac{p_j}{2}\right). $$ 
sst$z <- sign(sst$BETA) * qnorm(sst$P / 2, lower.tail = FALSE)
Because $\beta_j=z_j\mathrm{se}_j$ and $p_j$ were both derived from the same $z_j$ (with $\mathrm{se}_j>0$), this reconstruction recovers $z_j^{\mathrm{recovered}}=z_j$ exactly — the original, LD-correlated value from Section 3, regardless of what $\mathrm{se}_j$ was. Had beta and p instead been simulated separately (e.g. an independent $p\sim\mathrm{Unif}(0,1)$ paired with an unrelated $\beta$), this reconstruction would silently produce a different, inconsistent $z$ — quietly destroying the exact correlation structure Section 3 was built to guarantee, downstream of this script without any error being raised.

5. Block loop and assembly

The procedure above runs once per block in blk_names. A block with $m<2$ (m_snps < 2) is skipped, since there is no pair to correlate. Correlation is only ever simulated within a block, matching the block-diagonal approximation the reference panel itself uses — SNPs in different blocks are treated as uncorrelated, both here and in the panel that supplied $R$.

out_parts[[i]] <- data.frame(SNP = snplist, A1 = a1, A2 = a2, BETA = beta, P = p)
...
out <- do.call(rbind, out_parts)
utils::write.table(out, file = output_path, sep = "\t", row.names = FALSE, quote = FALSE)
Validated two ways (inst/dev-tests/null_sim_validation.png, null_z_distribution.png, not checked in): re-drawing $z$ 2,000 times for one block recovered the true $R$ with corr(true, empirical) $=0.996$; the marginal distribution of $z$ across the generated sumstats file matched $\mathcal{N}(0,1)$ closely, with a QQ-plot genomic inflation $\lambda=0.877$ — the expected mild deflation from correlated rather than independent tests, not a defect.
